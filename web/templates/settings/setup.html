Set up this computer

Comp HQ works best in a window of its own, with its own icon, like any other program — no address bar, no tabs. There are a few ways to set that up, in the order to try them. If the first doesn't work for you, the second doesn't depend on it.

{{/* The menu wording in ways 1 and 3 is what the browsers say as this was written and is checked against the computers in the office (PLAN P5-08). Browser menus move, so each step also says what it is for. */}}

1. Install it as an app — Edge or Chrome

This is the easiest: one menu item, and nothing to copy. Open Comp HQ in the browser first.

In Microsoft Edge

  1. Click the three dots ⋯ at the top right of the window.
  2. Choose Apps, then Install this site as an app.
  3. Click Install. If it asks whether to add a desktop shortcut or pin it, say yes.

In Google Chrome

  1. Click the three dots ⋮ at the top right of the window.
  2. Choose Save and share, then Install page as app…. (On some versions it is called Create shortcut… instead — if so, tick Open as window before you go on.)
  3. Click Install (or Create).

Comp HQ then opens in its own window, with the Comp HQ icon, and it is in the Start menu. If you can't find those menu items, or nothing seems to have happened, use way 2 — it doesn't need this one.

Then

  1. Right-click an empty spot on the Desktop, then choose New → Shortcut.
  2. Paste the command you copied (press Ctrl and V), then click Next.
  3. Type Comp HQ as the name, then click Finish.
  4. Double-click the new shortcut. Comp HQ opens in its own window.

If Windows says it can't find the program, right-click your browser's own icon, choose Properties, and look at the Target box: that is the real place it is installed. Put that in place of the path at the start of the command. If the shortcut's icon comes out blank or plain, see way 4.

3. Put it on the taskbar

  1. Open Comp HQ from the Start menu (if you used way 1) or from the desktop shortcut (if you used way 2). Its icon appears on the taskbar along the bottom of the screen.
  2. Right-click that icon and choose Pin to taskbar.

You can also right-click the desktop shortcut itself — on Windows 11 choose Show more options first — and choose Pin to taskbar.

4. If Windows shows a blank icon

Now and then Windows draws a shortcut with a blank page instead of the Comp HQ icon. Download the icon and choose it yourself:

Download icon

  1. Click Download icon. A file called Comp HQ.ico is saved, usually in your Downloads folder.
  2. Right-click the shortcut and choose Properties. (On Windows 11, choose Show more options first.)
  3. On the Shortcut tab click Change Icon…, then Browse…, choose Comp HQ.ico, and click OK twice.
