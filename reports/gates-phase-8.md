# Phase 8 gate checklist

Each row is one Phase 8 gate from SPEC.md A11 (8.01 to 8.91), with its plain description and the test file(s) that prove it. All rows passed in the full CI run https://github.com/stas-comp/comphq/actions/runs/44981364583 (`go`, `browser`, `container` with an upgrade and rollback against 1.5.0, `speed` and `screens`) and in the release run https://github.com/stas-comp/comphq/actions/runs/44983606331 (after one rerun of its container job; see the Phase 8 report). Gates 8.21, 8.53 and 8.82 (upgrade and rollback) are proved in the `container` job; gates 8.90 and 8.91 by the whole suite and the screen sweep, run once more with `COMPHQ_BRAND=mc`. Earlier phases' gates (1.01 to 7.91) are in `reports/gates-phase-1.md` and the other phase files, and all still pass.
