# Phase 5 gate checklist

Each row is one Phase 5 gate from SPEC.md Part A (5.01 to 5.17, 5.20 to 5.26, 5.30 and 5.31, listed individually), with its plain-English description, the test file(s) and test title(s) that prove it, and the result. Steps inside a job (5.01–5.17) are proved in the task window **and** on the task's own page, because the two draw one partial; the plain-form layer underneath is proved with JavaScript switched off before any script was written. Phase 1, 2, 3 and 4 gates are in `gates-phase-1.md` to `gates-phase-4.md` and are re-proven by the same run (gate 5.30).

**One gate has no automatic test, on purpose: 5.24** (the installed window shows no address bar). A test browser has no window to look at — it reports every bar as visible — so it is owner check O5.3; see D-78. What is proved automatically is everything that produces that window.

All rows below passed in the full CI run https://github.com/stas-comp/comphq/actions/runs/35618993521 (`go`, `browser`, `container` with the internet blocked and an upgrade-then-rollback against 1.1.0 with real steps in the database, `speed`, `screens`).
