# Phase 4 gate checklist

Each row is one Phase 4 gate from SPEC.md Part A (4.01 to 4.54, listed individually), with its plain-English description, the test file(s) and test title(s) that prove it, and the result. All rows passed in the full CI run https://github.com/stas-comp/comphq/actions/runs/35478917941 (`go`, `browser`, `container` with the internet blocked and an upgrade-then-rollback against 1.0.0, `speed`, `screens`) and again in the release run https://github.com/stas-comp/comphq/actions/runs/35480026380 for v1.1.0. Phase 1, 2 and 3 gates are in `gates-phase-1.md`, `gates-phase-2.md` and `gates-phase-3.md`, and are re-proven by the same run (gate 4.54).

Most "looks like the mockup" gates are proved by `e2e/design/`, which opens `docs/design/mockup.html` and the running app in one browser and compares the computed styles of matching elements; the colour and font tokens and the contrast rules are also pinned by `tools/policy/design_test.go`.
