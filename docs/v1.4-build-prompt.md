## Things that are easy to get wrong here

- **Prove the cause before fixing it.** SPEC B13 names a cause for each fault, found by reading the
  code, not by running it. Write each gate's test first and watch it fail against the current
  code. If it doesn't fail, the stated cause is wrong: find the real one and record it. This matters
  most for P7-01 (the white areas) and P7-10 (Word pictures).
- **Planned test corrections are not weakened tests.** Four earlier behaviours change on purpose:
  - gate 2.02's default column becomes To do (D-90);
  - gate 2.25's Unassigned column gains ideas;
  - gate 2.28's "Assign to…" button becomes the people list (D-92);
  - the sideways-scroll helper measures the whole page again (D-97).

  Correct those tests, put the gate number and D-entry in their titles or commit messages, and list
  them under "Tests corrected" in the report. Nothing else is weakened, skipped or deleted
  (`PLAN.md` §2.5).
- **Expand-only migrations** (SPEC B6): `0003_weekly.sql`, `0004_links.sql` (tasks) and
  `0006_article_order.sql` (kb) are new files, add-only, never edited after pushing. Each new piece
  of stored data is proven to survive a rollback to v1.3.0 and an upgrade again (7.39, 7.49, 7.59)
  in the container test, in the same way D-85's `@search-…` steps do.
- **"Today" is always `app.Today`,** never the wall clock. The weekly reset depends on it. Test it
  with `COMPHQ_TEST_TODAY` on a Friday, a Saturday, and with missed Saturdays.
- **Gate 4.11 stays at four icon-only buttons** (move up, move down, remove, give back). The new
  WEEKLY and WAITING are worded stamps. Move to To do and Undo are worded buttons. The unlink control
  is the existing **remove** icon.
- **The Knowledge Base search must not change.** Making the top bar's search per-section (P7-08)
  must leave every article-search gate (1.26–1.32, 6.30–6.35) passing exactly as before.
- **Every drag has a button, and every page works without JavaScript** (A2, `PLAN.md` §2.8). That
  includes Move to To do, the people list's link page, Undo's form, and linking from the job's own
  page.
- **Pushes and CI:**
  - Never push a `[skip ci]` commit together with code.
  - Never push while the previous push's CI is still running (it cancels that run). You may work
    on the next task locally meanwhile.
  - CI takes 15–25 minutes a push.
- **This machine:**
  - You can't take screen pictures or open a visible browser.
  - `SPEC.md` uses CRLF line endings. Keep each file's own line endings.
  - Write TypeScript and regex-heavy files with the file-writing tool, not shell heredocs.
