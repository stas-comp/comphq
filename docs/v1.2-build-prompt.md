## Things that are easy to get wrong here, so mind them

- **Build the plain forms before the script** (P5-02 before P5-03). Every step operation — add,
  tick, rename, remove, undo, reorder — must work with JavaScript switched off, as an ordinary form
  post, and be tested that way *first*. The script is layered over it afterwards. This is gate 5.08
  and SPEC A2 priority 2, and it is the same order the task window was built in at P4-08. Do not
  write the script first and retrofit the forms.
- **One template partial, two homes.** The steps list is a single partial included by both the task
  window and the task page at `/tasks/{id}`. Not two implementations. That is what makes gate 5.09
  real, and gate 4.27 stay true.
- **Ticks do not go into History** (D-71). Adding, renaming, removing and restoring a step do.
  Write the test that ticks ten steps and asserts History is unchanged — that test is the point.
- **Nothing is ever permanently deleted** (SPEC A3). A removed step sets `removed_at`, stays in the
  database, and still appears in `steps.csv`. The Undo is an interface convenience on top of that,
  not the safety net itself.
- **The migration is add-only.** A new table, never an edit to an existing migration file — the
  policy test enforces this. Rolling back to v1.1.0 must leave the rows untouched, and upgrading
  again must find them (gate 5.15). Prove it in the P5-09 release, not by assertion.
- **The icon has one source.** Draw the mark as SVG and render every raster size from it with a tool
  under `tools/`. Do not hand-export PNGs. Replace the two orange-square placeholders currently in
  `web/static/theme/icons/`.
- **`layout.html` currently links no icon at all.** That single omission is why desktop shortcuts
  come out blank, and fixing it is most of what makes the browsers' "install as an app" route work.
- **The Briefing must not change** (D-73). Write the test that asserts a job with unfinished steps
  briefs exactly as it does today.
- **`npm run check` before every push.** CI minutes are limited (D-03). Push once per task.
